Meu Primeiro Robô com Python

Crie uma automação que cadastra produtos em uma loja fictícia de celulares. Você vai ensinar seu computador a repetir tarefas usando Python, PyAutoGUI e uma planilha CSV.

Arquivos da atividade

Baixe os arquivos na mesma pasta. Os produtos são fictícios e servem apenas para esta oficina.

produtos.csv — 40 produtos pegar_posicao.py — descobrir coordenadas do mouse gabarito.py — referência comentada atualizar_precos.py — desafio extraLote 1 — celulares (CSV) Lote 2 — celulares (CSV) Lote 3 — acessórios (CSV) Lote 4 — fones (CSV)

O gabarito é uma referência: durante a aula, o código será construído gradualmente com o professor.

Roteiro da missão

  1. Entrar na loja (10 min). Abra a TecStore, clique em Área administrativa e use Admin / senai@123.
  2. Cadastro manual (15 min). Digite o primeiro produto, salve e confira a linha na tabela. Experimente editar um campo.
  3. Preparação (15 min). Baixe um lote CSV e crie codigo.py no VS Code. Instale as bibliotecas.
  4. Descobrir coordenadas (10 min). Execute pegar_posicao.py; anote a posição do primeiro campo. Deixe o navegador maximizado, com zoom 100%.
  5. Primeiro robô (25 min). Escreva o código gradualmente: sleep, click, write, press('tab') e press('enter'). Só execute depois de terminar e revisar.
  6. Repetição com CSV (30 min). Use pandas.read_csv() e for para preencher e salvar cada linha. Teste primeiro um lote pequeno e acompanhe a tabela.
  7. Nova rodada (15 min). Troque o arquivo CSV e execute novamente. Use os quatro lotes para praticar.
  8. Extra: reajuste (20 min). Abra a tabela de produtos e use atualizar_precos.py para aplicar um aumento percentual a todos os produtos cadastrados.
Atenção: o PyAutoGUI controla mouse e teclado reais. Use somente a loja simulada, mantenha a resolução e o zoom constantes e mova o cursor para o canto superior esquerdo para interromper a automação (failsafe).

Comandos que vamos aprender

import pyautogui # controla mouse e teclado import pandas as pd # lê a tabela de produtos import time # controla as esperas time.sleep(2) # aguarda 2 segundos pyautogui.click(x, y) # clica numa posição pyautogui.write("Oi") # digita texto pyautogui.press("tab") # pressiona uma tecla pyautogui.hotkey("ctrl", "a") # seleciona tudo tabela = pd.read_csv("produtos.csv") for indice, produto in tabela.iterrows(): print(produto["modelo"]) # repete para cada linha

Instalação no terminal: python -m pip install pyautogui pandas.
